# STEP SEM-3 — Week 7 Java

Category C: Encapsulation & Access Control

## Folder structure
- `Assignment/Q1` to `Assignment/Q5`: assignment solutions
- `Practice/Q1` to `Practice/Q5`: practice solutions

Each question folder contains:
- `Main.java` — runnable Java solution
- `Output.txt` — sample output
- `README.md` — title and run instructions

## Run a solution
Open Terminal in the question's folder and run:
```bash
javac Main.java
java Main
```
